## English Version

### Description
Arcade 2D mini game project in Python demonstrating user input handling, sprite animation physics, and audio playback.

### Tech Stack
* **Language:** Python
* **Game Engine:** `pygame`

### Quick Start
```bash
git clone https://github.com/Bargaisl/python-arcade-mini-game.git
cd python-arcade-mini-game
pip install pygame
python "two towers.py"
```
