# Python Arcade 2D Mini Game 🎮

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue.svg)](https://www.python.org/)
[![Pygame](https://img.shields.io/badge/Pygame-2D%20Engine-yellow.svg)](https://www.pygame.org/)

Аркадный игровой 2D-проект на Python для демонстрации обработки пользовательского ввода, анимации спрайтов и воспроизведения аудио эффектов.

---

## 🛠️ Стек технологий

* **Язык:** Python
* **Игровой движок / Библиотека:** `pygame`

---

## 🚀 Запуск

```bash
git clone https://github.com/Bargaisl/python-arcade-mini-game.git
cd python-arcade-mini-game
pip install pygame
python "two towers.py"
```
